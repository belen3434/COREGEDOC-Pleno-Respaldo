# Modulo de Pleno

Esta carpeta corresponde al modulo de pleno del proyecto COREGEDOC.

Fue creada como una estructura separada del codigo original para no afectar el sistema existente. No contiene conexion a base de datos, CRUD real, logica de votacion ni firma electronica.

## Estructura

- `controllers/`: controlador base del modulo.
- `models/`: modelos base sin logica compleja.
- `views/`: vistas iniciales con HTML basico.
- `assets/css/`: estilos propios del modulo.
- `assets/js/`: scripts propios del modulo.
