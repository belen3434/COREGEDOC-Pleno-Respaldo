# COREGEDOC - Módulo Pleno

## Descripción del Proyecto

Proyecto desarrollado para el Consejo Regional de Valparaíso (CORE), cuyo objetivo fue diseñar e implementar el Módulo Pleno dentro de la plataforma COREGEDOC.

La solución permite gestionar sesiones plenarias, organizar la tabla del día, realizar votaciones, registrar acuerdos y generar certificados, optimizando el trabajo de la Secretaría de Pleno y reduciendo procesos manuales.
